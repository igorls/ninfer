NInfer for Windows

This is an unsigned installer for Windows 11 x64 and NVIDIA Blackwell
sm_120 GPUs. The primary test targets are RTX 5090 (32 GB) and RTX PRO 6000
Blackwell (96 GB). RTX 3090 and RTX 4090 are not supported by this build.
Use a current NVIDIA driver with CUDA 13.3 support or newer. No CUDA Toolkit,
Visual Studio, CMake, Python, or Hugging Face CLI is needed to run the app.

Install, open NInfer from Start, and select a downloaded v3 .ninfer entry file.
Use Qwen3.8-27B NVFP4 for the 5090 test. Model download links are available
in the setup window. Model weights are not included in the installer.
Flash-Next can use resident execution on a 96 GB GPU or bounded expert offload
on smaller GPUs. Offload needs over 63 GiB of expert backing alone, plus RAM
for the OS and runtime; a 64 GB workstation is insufficient. Read the model
card and qualification limits before downloading.
The published legacy Flash-Next entry needs offline reframing before this engine
can load it. The setup window links to the compatible-artifact preparation guide;
choose the prepared canonical entry and keep its continuation files beside it.

The initial profile uses a 16K context per request, a 32K shared KV pool,
two request lanes, FP8 KV, and an 8 GiB desktop reserve. Artifacts with an MTP
component use three draft tokens. Qwen3_5MTP uses the optimized proposal head;
Flash-Next uses its full shared head. Artifacts without MTP use ordinary decoding. Vision libraries
are bundled; Vision is opt-in through the Supervisor settings. The HTTP
API listens only on 127.0.0.1:8010 and the dashboard on 127.0.0.1:8099.
The full model is validated by the engine when it loads.

Models stay where you downloaded them. Settings and logs are stored in
%LOCALAPPDATA%\NInfer. Uninstall keeps these files. Quit NInfer from its
tray menu before updating or uninstalling. Login startup can be enabled
from the tray after configuration.

This build is unsigned. Windows may show an unknown-publisher warning.
The matching SHA256SUMS file identifies the installer provided for testing.
