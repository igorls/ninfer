HOW TO PLAY

Drag a face to turn it; the layer follows your pointer and settles on the nearest quarter. Tap a face for a clockwise turn, Shift-tap for counterclockwise, Alt-tap for a half turn. Keys U D L R F B do the same. Drag the space around the cube, or use the arrow keys, to look around it. P pauses.

Your clock starts with your first turn. Qwen's clock runs only while a request is out, and local search's only while it searches. Scramble playback, the warm-up request and turn animation stay off every clock, so turn speed never changes a time.

Both Qwen modes see the six faces, move history and available turns, with the misplaced stickers each turn would leave. Avoid repeats excludes turns leading to a previously visited position; Allow repeats offers all eighteen turns. Reasoning plans before answering; System One selects from next-token probabilities. The local solver grades every turn afterward. That grade never reaches the model.
