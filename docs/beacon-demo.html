QWEN CONNECTION

Requires the image-enabled System One build, --vision and --cors. Port 8014 is the local candidate; change it to your server. Keys stay in this page.

HOW TO PLAY

Guide the cyan triangle into yellow rings. Avoid gray walls and red moving hazards. Rings collected and separate contacts are counted for the human observer.

Drag a wall or beacon during a run to change the scene. Or select an object below the arena and use the nudge buttons. Qwen learns about edits only through its next image.

Run first verifies image processing without moving. Camera changes pause and brake the drone; Resume starts a new observation. Hidden tabs pause automatically. A blackout should produce Brake; frozen and delayed images may mislead the pilot.

This is a visual control experiment, not a navigation benchmark. The model has no map or action history. Arrow keys work with the arena focused in human mode; P pauses.
